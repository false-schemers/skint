# SKINT Precursors
                         
This directory contains Scheme code for autogenerated parts of SKINT C source code. 
To re-generate these C files, one has to have working version of SKINT interpreter. 
Generation is performed with the help of Skint scripts located here (they have the `.ssc` suffix). Assuming that the `skint` binary is just above
the skint directory tree, the following commands will do the trick:

```
$ ./skint skint/pre/scm2c.ssc skint/pre/s.scm skint/s.c
$ ./skint skint/pre/scm2c.ssc skint/pre/t.scm skint/t.c
```

`k.sf`, `n.sf` and `ksf2c.ssc` are retired. `k.c` was generated from `k.sf` by the
[SFC compiler](https://github.com/false-schemers/sharpF) and patched by `ksf2c.ssc`;
it is hand-written now, so nothing here is used to build it, and SFC is no longer
needed to bootstrap SKINT. `n.sf` was only ever loaded by `k.sf`.

Please note that this step is optional, but may be needed to make enhancements and fix bugs in the
autogenerated C code.
